## web.walls for Android 1.8

Animated HTML live wallpapers for your phone. Same scenes as the Windows app, plus a few phone-only ones.

### Install
1. Download **WebWalls-Android-1.8.apk** below (under *Assets*) on your phone.
2. Tap it. If Android asks, allow installing from your browser / file manager.
3. Open **web.walls**, pick a wallpaper and set it as your live wallpaper.

Already on 1.7? It installs straight over the top. Coming from 1.6 or older, uninstall the old one first (it was signed with a different key).

### What's new
- **Neon Galaxy**: an OLED-tuned GPU galaxy. True-black space (pixels fully off), saturated nebulae, a spinning spiral, parallax stars and shooting stars. Everything drifts and colour-cycles so nothing burns in.
- 13 wallpapers total. Works on phones, tablets, foldables and DeX, in any orientation.

*Windows version: grab the latest **WebWalls-Setup** from the [Releases page](https://github.com/MatsuYoda-88/webwalls/releases/latest).*
